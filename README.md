# TecHub

Plataforma web desenvolvida para divulgação e exploração de projetos, permitindo que criadores publiquem seus trabalhos e visitantes conheçam novas ideias e iniciativas.

## Sobre o projeto

O TecHub está sendo desenvolvido como parte de um trabalho acadêmico em grupo.

A aplicação possui dois tipos principais de usuários:

- **Criador:** poderá cadastrar e divulgar seus projetos.
- **Visitante:** poderá explorar e conhecer os projetos publicados na plataforma.

## Páginas

Nesta etapa do projeto estão sendo desenvolvidas:

- HomePage
- SignUpPage
- NewProjectPage

## Tecnologias

O frontend utiliza:

- React
- React Router
- Vite
- CSS

## Organização

O projeto busca separar elementos reutilizáveis em componentes, evitando repetição de código.

Alguns exemplos são:

- `Header`
- `FeatureCard`

As páginas ficam organizadas separadamente dentro de `src/pages`.

## Trabalho em equipe

O desenvolvimento é realizado utilizando branches separadas para cada funcionalidade.

Exemplo:

- `sprint-homepage`
- `feature/signup`
- `feature/new-project`

Depois de concluídas, as funcionalidades poderão ser integradas ao projeto por meio de Pull Requests.

## Projeto base

O TecHub foi desenvolvido a partir do projeto didático **Órbita**, disponibilizado como base para a disciplina.

A estrutura original está sendo adaptada para atender aos requisitos e à identidade visual do TecHub.
